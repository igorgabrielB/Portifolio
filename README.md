# 🚀 Portfólio - Desenvolvedor Full Stack

Um portfólio moderno e ousado desenvolvido com React, Vite e Tailwind CSS. Design responsivo com paleta roxo/preto que impressiona.

## 🎨 Características

- **Design Moderno**: Paleta roxo profundo + preto com gradientes sofisticados
- **Totalmente Responsivo**: Mobile-first, otimizado para todos os dispositivos
- **Animações Suaves**: Implementadas com Framer Motion
- **Performance**: Vite para build rápido e otimizado
- **Componentes Reutilizáveis**: Arquitetura limpa e modular
- **SEO Friendly**: Meta tags e estrutura semântica

## 📋 Seções

- **Hero**: Introdução impactante com CTA
- **Sobre**: Biografia e habilidades técnicas
- **Projetos**: Showcase dos 2 projetos principais
- **Contato**: Formulário + links de redes sociais
- **Footer**: Links rápidos e informações

## 🛠 Tech Stack

- **Frontend**: React 18 + Vite
- **Styling**: Tailwind CSS 3
- **Animações**: Framer Motion
- **Ícones**: React Icons
- **Build Tool**: Vite

## 🚀 Como Rodar

### Instalação

```bash
# Instalar dependências
npm install
```

### Desenvolvimento

```bash
# Rodar servidor de desenvolvimento
npm run dev
```

Acesse em `http://localhost:3000`

### Build para Produção

```bash
# Gerar build otimizado
npm run build

# Visualizar build
npm run preview
```

## 💡 Customização

### Cores Primárias
Edite `tailwind.config.js` para ajustar a paleta de roxo/preto

### Conteúdo
Edite os arquivos em `src/pages/` para adicionar seu conteúdo

### Componentes
Reutilize `<Button>`, `<Card>`, `<SectionTitle>` em novas seções
